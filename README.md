# 🌱 Smart Campus

Smart Campus is a lightweight, all-in-one student productivity dashboard. It brings together task management, note-taking, scheduling, a Pomodoro study timer, and study resources in one clean web app — built with plain HTML, CSS, and JavaScript.

**Live Demo:** [smart-campus-eight-tau.vercel.app](https://smart-campus-eight-tau.vercel.app)

## ✨ Features

- **📊 Dashboard** — At-a-glance overview of total tasks, notes, study time, and scheduled sessions, plus a task progress tracker.
- **✅ Tasks** — Add, filter, and manage academic tasks by priority (High/Medium/Low) and category (Academic, Assignment, Exam, Personal), with due dates and completion status.
- **📝 Notes** — Create and save study notes for quick reference.
- **📅 Schedule** — Plan and view upcoming study sessions and events.
- **⏱️ Study Timer** — A built-in Pomodoro-style timer to help you focus, with session, streak, and total study-minute tracking.
- **📚 Resources** — A dedicated space to organize helpful study resources and links.

## 🛠️ Tech Stack

- **HTML5** — page structure
- **CSS3** — styling and layout
- **JavaScript (Vanilla)** — interactivity and app logic
- **Vercel** — hosting/deployment

## 🚀 Getting Started

No build tools or dependencies required — it's a static site.

1. **Clone the repository**
   ```bash
   git clone https://github.com/hemarukesh/Smart-Campus.git
   cd Smart-Campus
   ```

2. **Open it in your browser**
   Simply open `index.html` in any modern web browser, or serve it locally:
   ```bash
   npx serve .
   ```

3. **Start exploring**
   Navigate between Dashboard, Tasks, Notes, Schedule, Study Timer, and Resources from the sidebar menu.

## 📖 Usage

- Head to **Tasks** to add academic to-dos with a due date, priority, and category.
- Use **Notes** to jot down and save quick study notes.
- Check **Schedule** to plan out your study sessions and events.
- Use the **Study Timer** to run focused Pomodoro sessions and track your streaks.
- Browse **Resources** for handy study materials and links.
